# Vibe Research Runtime

Vibe Research 是一个本地科研工作台。它用可追溯的研究图连接问题、论文、证据、假设、实验、结果和产物，并把检索覆盖、全文精读与研究接续保存在用户选择的独立工作区中。

## 使用入口

安装插件并重启 Codex 后，在 Vibe Research 项目中开始或继续对话。研究伴侣会以收起状态出现；点击可打开研究现场，拖动可调整入口位置。也可以在终端运行 `vr-workbench`，Windows 使用 `vr-workbench.cmd`。

研究工作区与插件程序分离。更新或卸载插件不会删除研究项目，发布包也不包含开发者的研究数据、数据库凭据或登录状态。

## 研究图

研究状态只能通过 `vr` 命令修改。节点保存在 `nodes.json`，分支与有向边保存在 `branches.json`；SQLite 负责事务事实，Markdown 与 HTML 作为可读投影。过程关系保持无环，引用、反驳等语义关系可以形成反馈环。

常用命令：

```text
vr branch add --title "路线名称"
vr node add H --title "待检验假设" --branch B0001
vr edge add G0001 motivates H0001
vr transition H0001 active --reason "开始验证"
vr trace H0001
```

## 文献检索与精读

快速检索适合发现候选；正式综述应使用持久检索队列记录每个来源的游标、限流等待与缺页。候选论文经初筛判定有价值后立即进入系统精读；没有全文时保留明确的待获取状态。精读记录绑定原文、页码、文档版本与解释审阅状态，不把摘要阅读或文字匹配当作完成精读。

数据库连接、社区技能与工作流程见 `docs/`。首次使用建议从工作台向导完成项目、来源和 PDF 环境检查；密钥只保存在接收方本机。

## 数据边界

项目备份使用 `vr bundle create`。备份不包含数据库凭据、机构登录态、外部代码仓库或 Codex 对话。恢复到新设备后先运行 `vr doctor` 和来源连接检查，再继续研究。
